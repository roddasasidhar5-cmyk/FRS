# AttendAI — Face Recognition Attendance System

AI-powered attendance system using real-time face recognition, liveness detection (blink),
and a modern React frontend. Faculty verify via face before marking student attendance.

---

## Project Structure

```
AttendAI/
│
├── api.py                  ← Flask backend (main server — run this)
├── requirements.txt        ← Python dependencies
├── attendance.db           ← SQLite database (auto-created on first run)
│
├── gen_cert.py             ← Generate SSL certificate for HTTPS / mobile camera
├── inspect_db.py           ← CLI tool to view database contents
├── open_firewall.bat       ← Opens ports 5443 & 5173 in Windows Firewall (run as Admin)
│
├── cert.pem                ← SSL certificate (generated by gen_cert.py)
├── key.pem                 ← SSL private key  (generated by gen_cert.py)
├── .secret_key             ← Flask session secret (auto-generated)
│
├── static/
│   ├── faces/              ← Student face photos (uploaded via the app)
│   ├── user_faces/         ← Faculty face photos
│   └── react/              ← React production build output (generated by npm run build)
│
└── frontend/               ← React + Vite frontend source
    ├── src/
    │   ├── pages/          ← Dashboard, Students, Classes, Reports, AttendanceSession …
    │   ├── components/     ← Layout (sidebar), CameraView
    │   ├── context/        ← AuthContext
    │   └── api/            ← Axios client
    ├── package.json
    └── vite.config.js
```

## Quick Start

### 1. Install Python dependencies
```powershell
pip install -r requirements.txt
```

### 2. Generate SSL certificate (required for mobile camera)
```powershell
python gen_cert.py
```

### 3. Open firewall (first time only, run as Administrator)
```powershell
# Right-click open_firewall.bat → Run as administrator
```

### 4. Start the backend
```powershell
python api.py
```

### 5. Start the frontend (separate terminal)
```powershell
cd frontend
npm install       # first time only
npm run dev
```

### 6. Open in browser
- **PC:** http://localhost:5173/
- **Mobile (same WiFi):** http://\<YOUR-LAN-IP\>:5173/

Default login: `admin` / `admin123`

---

## Mobile SSL Warning Fix

On first mobile visit, open `https://<LAN-IP>:5443` → Advanced → Proceed.
Or install `attendai.crt` (generated by `gen_cert.py`) as a trusted CA on your phone.

## Key Features

| Feature | Details |
|---|---|
| Face recognition | dlib HOG + face_recognition library |
| Liveness detection | Blink detection (EAR — Eye Aspect Ratio) |
| Duplicate prevention | Unique DB index on (student, class, date) |
| Crash recovery | Faculty verification + attendance persisted to DB |
| Bulk student upload | CSV drag-drop with live preview |
| Attendance % | Per-student percentage with 75% threshold |
| Role-based access | super_admin sees everything; faculty sees students only |
| Mobile camera | Flip button (front ↔ rear) on all camera views |
| Concurrent users | Threaded Flask — 3–6 faculty simultaneously |
